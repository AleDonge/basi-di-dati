# Avvio rapido — Database Academy con Codex

> Queste sono le istruzioni iniziali del pacchetto. In questa cartella gli Sprint
> 0–5 sono già implementati: per avviare e verificare l’app usare `README.md`
> e `docs/SPRINT5_ACCEPTANCE.md`, senza ricreare la cartella o ricopiare le fonti.

1. Crea una cartella vuota `database-academy` sul PC.
2. Copia al suo interno **tutti i file di questo pacchetto** (`PROJECT_SPEC.md`, `AGENTS.md`, `CONTENT_INVENTORY.md`, `ROADMAP.md`, `PROMPT_CODEX.md`).
3. Crea la sottocartella `source-material/` e copia al suo interno **i 13 file originali** ricevuti dal professore (10 PDF e 3 TXT), mantenendo i nomi. I file originali NON sono inclusi nello ZIP per evitare un duplicato di circa 80 MB.
4. Apri la cartella `database-academy` con Codex (IDE o CLI) e incolla il contenuto di `PROMPT_CODEX.md`.
5. Fai completare lo Sprint 0 e controlla la prima versione nel browser. Poi richiedi lo Sprint 1, quindi Sprint 2 e così via.

## Prompt per le settimane successive
